> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. **Goal:** Split otherwise unplaceable body rows into independently advancing cell units while preserving successful existing short-table and whole-row bytes.

**Architecture:** Measure copied text/image ranges once, retain line/image metadata and per-cell cursors, and isolate candidate slicing/terminal fit in TableRowFragmentation. Keep the legacy short/whole-row fast paths; TablePagination composes affected-page plans and TextLayout owns page/ancestor state and command charging.

**Tech Stack:** Existing C#/.NET projects and NUnit; current Python/pypdf/Poppler oracle and Node/browser WASM probe. No new runtime dependency or public options.

**Spec:** `docs/superpowers/specs/2026-10-24-table-row-fragmentation-design.md` (including the integration/S7, load-bearing accounting, and adopted-decisions sections). Never infer expected values from the implementation's output.
- Preserve `U=PageHeight-2*Margin`, 0.000001pt fit tolerance, existing resolved length<=14,400pt, explicit1–16 tracks and0.001pt track-sum tolerance. All accumulations finite. Existing limits and diagnostic codes remain.
- No rowspan, nested cell blocks/lists/tables, new CSS or auto columns; no new options/resource protocol; no general block/serializer rewrite. Formal page furniture follows completed business tables; fixed delivery follows page furniture.
- Short tables with Height<=U remain indivisible, including required-ancestor-leading failure. Only body rows failing fresh fit in long tables may split. Header never splits. No header-only or decoration-only continuation.
- Copy actual AppendLine run ranges before borrowed glyph buffers advance. No rewrap, suffix copies, fake blank-line commands or duplicate full-cell/slice charges. Charge actual copied runs/images once, actual cell slices once, header repeats again.

## Review focus

- Initial margins carried by a deferred cell are independent of global row first-fragment state; S7 is mandatory, along with impossible-start rejection before neighboring progress.
- A zero-run br line advances real positive geometry; whitespace/empty p and large edge-only cells must not manufacture progress or pages.
- Terminal max across unequal cells and bottom lookahead must reserve an actual unit, including images; no detached bottom-only page or unbounded rollback.
- Splittable eligibility includes header/table/required ancestor first edges and terminal table bottom; a short table remains indivisible despite ancestor pressure.
- Acceptance negatives are distributed across core tests, executable API probes, file manifests and browser cases. Migrate only newly accepted oversized bodies; retain genuine atomic and short-table leading failures.
