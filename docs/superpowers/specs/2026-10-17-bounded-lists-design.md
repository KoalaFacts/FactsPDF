# C2：受限列表与分页契约

日期：2026-10-17。基线：main `4bd5a3826a46b2848faba2eb5d4505638592cfea`，C1 已合并。

状态：用户要求继续既定路线，先完成最小设计、双语跨页样例和独立设计复核，再在没有新增产品决策时继续最小实现。独立设计复核通过，无 Critical/Important；两个明确性建议已纳入（空段落 strut 局部例外、CSS 先行校验顺序）。无需新增用户产品决策。本稿不是当前支持声明；不重复 C1 验收，不包含数据库、发布或 Pages 设置变更。

## 1. 目的与方案

中英报告需要十进制有序列表、无序列表、最多两级嵌套，换行和跨页时标记、编号与正文保持正确关系。复用严格 HTML 树、字体角色、块盒模型、行级分页、共享 PDF 输出及资源边界，不增加公共配置、CLI 参数或运行时依赖。

采用保留 `ol/ul/li` 结构和独立标记栏的方案：每个列表先按直接子项测量统一栏宽，再通过现有块遍历排正文，标记仅随每项第一行放置一次。直接拼接文字前缀无法保持续行缩进；通用 CSS 计数器/marker 伪元素系统超出此次范围。

## 2. HTML 与编号

- 新增 `ol`、`ul`、`li`。列表直属子元素只能是 `li`；空白/注释允许，非空白文本、`style` 或其他直属元素报 `FPDF1101`。`li` 必须直属 `ol/ul`。
- `li` 中保留现有行内、段落、块容器，可在其中嵌套一个或多个列表。列表嵌套深度按祖先 `ol/ul` 计算，最多两级（顶层为 1）；第三级在其起始标签报 `FPDF1101`。新列表不能作为列表的直接子元素。
- 每个 `ol` 从 `1.` 开始，仅按其直接 `li` 的源顺序递增，空项也计数。子列表独立从 1 开始；独立兄弟列表重新从 1 开始。同一项或同一列表跨页不重置、不补发标记。
- 不支持 `start`、`reversed`、`type`、`li value`，沿用 `FPDF1103`。不静默忽略这些属性，不增加计数器 API。
- 可省略 `li` 结束标签，但只在下一个直属 `li` 或所属列表结束标签前自动闭合；先按现有规则闭合可省略的 `p`。未闭合行内/普通块不自动修复，列表结束标签不能省略。显式 `</li>`、HTML 大小写、现有实体与选择器规则保留。

## 3. 标记、宽度和续行

`ol` 标记是可搜索、可提取的真实十进制文本，使用所属 `li` 的计算字体字号、角色、颜色和角色内逐字 fallback；缺字/缺角色沿用原字体错误。`ul` 使用实心圆盘（两级均相同），由 PDF 向量绘制，颜色来自 `li`，直径为 `0.3 × li 字号`，圆心在第一行基线上方 `0.3 × li 字号`。圆盘不是字体字符，不因普通 ASCII 列表而要求额外字体，也不承诺文本提取包含圆盘字符。正文仍可搜索复制，不宣称 Tagged PDF。

每个列表按所有直属 `li` 的真实标记宽度取最大值 W；列表计算字号 S，标记与 item 外边框之间间距 G=`0.5S`，统一栏宽 I=`max(2S, W+G)`。`ol` 用实际 advance，`ul` 用圆盘直径。标记在栏内右对齐，右边界是列表内容左边界+I−G；所有 item 外盒从列表内容左边界+I 开始。列表无项则无标记栏/行盒。

标记栏在列表内容区内，独立于列表本身 padding/border。`li` 的 width/padding/border 相对于扣除 I 后的内容宽度按现有规则解析；其左 padding 会进一步移动正文，不能把标记推到容器外。嵌套列表从父项内容区继续缩进。续行、后续段落、跨页正文沿用所属 item 内容区；text-align 只对正文在该区内对齐，标记栏不跟着居中或右移。宽度不足不裁剪、不压缩、不重叠，报 `FPDF1302`。

标记附着于 item 中遇到的首个段落（包括空段落），可穿过普通块容器，但不借用子列表的段落。如果 item 在首个子列表之前没有自己的段落，则在 item 开头生成一条仅承载标记的行；全空 item 同样产生一条标记行。附着空段落保留该段落的分页/边距样式。标记所用 item 字体 strut 与正文第一行共同决定第一行 ascent/descent，避免大标记越界；其后的行保持原正文度量。圆盘边界也必须位于第一行盒内。

承载标记的空段落会生成一条 strut 行，这是原空段落不生成文字行的局部例外；没有标记的空段落保持原行为。独立验证 `<li><p></p><p>正文</p></li>`、首个空段落显式分页、子列表先出现三种情况。

## 4. 分页、keep 与盒模型

标记与第一行是同一个不可分割的放置动作：剩余高度不足时一起移至下一页；标记不能留在上一页。长项按现有行级算法自然分页，续页不重复标记；后续 item 按源序继续编号。不新增整项 keep 或通用孤行控制，允许一行正文落在前页/后页。`break-inside:avoid`、`orphans`、`widows` 等仍明确不支持。

`ol/ul/li` 作为块容器支持既有 width、padding、solid border、background、继承文字样式及选择器。容器仍不支持 margin-top/bottom 和 break-before/after；需要显式分页或段落间距时使用 item 内的现有 `p/h1…h6`。这些段落的 auto/page break、margin 合并、空段落和首行高规则保持。

列表和 item 装饰复用 slice：首片段顶部边框/内边距，续页背景/侧边框，末片段底部边框/内边距；不 clone、不在续页重复标记栏的内容。列表背景覆盖标记栏，item 背景只覆盖 item 外盒。顶层无 paint 的纯空列表不产生额外页面；首行+padding 不可容纳和末尾装饰越界仍按现有明确错误处理，不能无限新建页或产生幽灵页。

## 5. 内部边界与兼容

解析器保留新块名及严格结构。独立 `ListLayout` 负责 item 标记绑定、列表栏宽和数字测量；`BlockLayout` 只消费测量后的标记栏/首段落标记信息，将栏宽从 item 容器可用宽度扣除。`TextLayout` 将标记度量合入首行，完成分页后一起添加真实数字 runs 或圆盘。共享 painter 增加一个有界圆盘 primitive，两条 PDF 序列化路径复用。

遍历保持迭代和有界，允许每个列表对直属子项线性测量，不全局复制段落/行；不可递归到任意普通块深度而绕过已有深度边界。新增标记使用已有字体对象/ToUnicode/子集，数字不凭名称合并字体。旧无列表输入的 PDF 字节、错误、默认值及 C1 角色契约保持。

不新增公共资源限额。ol/ul/li 计入 MaxElements/MaxDepth；标记真实 text runs 或一个圆盘各计入 MaxDisplayCommands，在保留前收费。MaxInputCharacters、MaxCss*、字体字节、MaxPages、MaxOutputBytes 和取消均保留。标记测量中检查取消；编号最大受已验证元素总量约束，不发生整数溢出。

错误：结构/三级嵌套 `1101`；原未知元素 `1102`；属性 `1103`；不支持 CSS `1201/1202`；几何 `1302`；页数 `1303`；命令/字节 `1401`；缺字体沿用 `1301/1504/1507`。列表引入的结构/几何/字体标记错误提供可用 list/item 源偏移。最终复制前失败保护输出流内容/位置；CLI 保留文件哨兵、stdout 无 PDF、新目标不存在，取消与最终 I/O 的原边界不变。

错误顺序保留先收集/校验全部 CSS，再解析 HTML 结构的现有规则。列表直属 `style` 的 CSS 合法时是结构 `1101`；其中若含不支持的 CSS，先报 `1201/1202`。不为新列表错误改写旧 CSS 预检顺序。

## 6. 验收与最小交付

固定双语样例 `examples/lists-report.html`，A4、36pt margin、12pt 默认、1.5 line-height，220pt 报告内容，含：至少 12 个顶层编号项（穿过 9→10）、长项自然跨页、两级 ol/ul 混合、跨页父边框、显式段落分页后的连续编号、独立列表重启、空项和列表后普通文本。只复用已有明确字体来源，不分发独立字体，不修改嵌入许可。

另有小几何/ASCII fixture，采用 Courier 已知 advance 手算栏宽、首行/续行坐标，不能从待测结果自动生成预期坐标。二语 fixture 的正文块、项 ID 顺序、预期标记集合独立写入检查器；真实分页发生后记录页数与逐页审阅，不把运行输出自动冻结成已批准参考。
